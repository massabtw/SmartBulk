# Agent Guidelines

## Agent skills

### Issue tracker

Local markdown files under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical five-role triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout (`GLOSSARY.md` and `docs/adr/` at repo root). See `docs/agents/domain.md`.

### C# / .NET Backend Standards

Padrões obrigatórios C#/.NET do Grupo Madero (camadas Api, Application, Domain, Infrastructure). Consulte `.agents/skills/backend/SKILL.md` e `.agents/skills/mandatory-rules.md`.

### Frontend & UI/UX Standards

Padrões modernos para Next.js (App Router), React, Tailwind CSS e Framer Motion:
- **Next.js App Router**: `.agents/skills/nextjs-app-router-patterns/SKILL.md`
- **React & Performance (Vercel)**: `.agents/skills/vercel-react-best-practices/SKILL.md` e `.agents/skills/vercel-composition-patterns/SKILL.md`
- **Design & Acessibilidade**: `.agents/skills/web-design-guidelines/SKILL.md`
- **Tailwind CSS**: `.agents/skills/tailwind-design-system/SKILL.md`
- **Animações & Motion**: `.agents/skills/framer-motion-animator/SKILL.md`, `.agents/skills/framer-motion/SKILL.md` e `.agents/skills/vercel-react-view-transitions/SKILL.md`
